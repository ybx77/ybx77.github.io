# ybx77.github.io

个人 GitHub Pages 站点，内容由本仓库 `main` 分支直接发布。

线上地址：<https://ybx77.github.io>

## 说明

- 纯静态页面，推送到 `main` 分支后由 GitHub Pages 自动构建，无需额外配置。
- 站点主体是 `index.html`，配套资源放在 `Range_files/` 目录下。

## 本地预览

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```
